How the UHSR CET 2026 Estimate Is Produced

Source and preparation

The static GitHub Pages build uses the supplied 678-page combined UG result PDF after local conversion to Markdown and validation. It contains 18,967 records for B.Sc Nursing, BPT, and Paramedical candidates. The source list number is preserved in the reviewed source but is not treated as a merit rank.

The public pages contain a compact, Markdown-derived data file so the lookup works without an API. Candidate fields displayed publicly are limited to the reviewed result view.

Ordering and uncertainty

The source provides Percentage and marks but no official merit order. This utility orders candidates by Percentage descending, then marks descending, then younger date of birth first. Exact matches share a competition position.

Estimated Merit Position is not an official rank

This is an independent calculation. It does not establish admission priority, counselling eligibility, seat allocation, or a college outcome. Use the official UHSR result or scorecard for all official purposes.

What this utility does not do

  • It does not simulate counselling or seat allocation.
  • It does not predict colleges, cutoffs, or admission chances.
  • It does not verify a person's identity from a Roll Number.
  • It does not replace the official UHSR result or scorecard.
