## Global Rules — Non-Negotiable Across All Prompts

These rules apply to every file produced by every prompt. No prompt overrides them. No exception.

### Identity & Branding
- NEVER claim to be UHSR or affiliated with UHSR in any way
- NEVER use UHSR logo, Haryana emblem, government seal, or any official imagery
- ALWAYS brand as: `UHSR CET Rank Calculator 2026 — Independent Candidate Utility`
- NEVER use the word "Official" to describe our own product
- ALWAYS include a link to `https://www.uhsrcetadmissions.in/` on every public page

### Terminology
- ALWAYS say **"Estimated Merit Position"** — never just "Rank" or "Your Rank"
- ALWAYS say **"Independent Candidate Utility"** in the subheading/branding
- PDF reports MUST be watermarked: **"UNOFFICIAL — ESTIMATED MERIT POSITION"**
- Dataset state before import is ALWAYS: **"UHSR CET 2026 Result Data Not Yet Available"**

### Data Integrity
- NEVER display fake candidates, fake ranks, fake statistics, or fake countdowns
- NEVER activate the calculator with test/placeholder data visible to the public
- NEVER process the source PDF/Markdown on every user request — process ONCE, store in DB, serve from DB
- When a dataset fails validation, it MUST NOT be published

### Ranking Integrity
- NEVER hardcode UHSR's ranking algorithm as if it is verified
- The config version string `"v1-UNVERIFIED-placeholder"` MUST trigger `ranking_disclaimer` on all result pages
- The disclaimer must be visually prominent (orange notice box), not hidden in small print
- The ranking engine MUST be configurable — criteria defined in `ranking_config.py`, not scattered through business logic

### Security
- `ADMIN_SECRET` MUST live in environment variables — never hardcoded in any file
- `/admin.html` MUST NOT be linked from any public page (index, result, faq, methodology)
- CORS MUST be restricted to `settings.allowed_origin` in production — never `*`
- ALL database queries MUST be parameterized (SQLAlchemy handles this — never use Python string formatting in SQL)
- Cache-Control: `no-store` on all `/admin/*` routes

### Design
- MUST visit `https://www.uhsrcetadmissions.in/` before writing any CSS
- MUST use ONLY the CSS custom properties defined in `02_ARCHITECTURE.md` — no additional colours or fonts
- Zero border-radius everywhere (2px absolute maximum). No box-shadow. No gradient backgrounds. No external CSS frameworks (no Bootstrap, Tailwind, etc.)
- No CSS animations or transitions
- Mobile-responsive breakpoint at 768px

### Notice Box
Every public page MUST contain this Important Notice box (see exact HTML template in `02_ARCHITECTURE.md`):

> This website is an independent candidate utility and is NOT affiliated with, operated by, or endorsed by UHSR or the Department of Medical Education and Research, Government of Haryana. The estimated merit position shown here is independently calculated from publicly available data. Always refer to the official UHSR result for counselling. → Visit Official UHSR CET Portal

## How Prompts Work

`03_PROMPTS.md` contains seven prompts. Each prompt:
1. Has a **Metadata block** (phase, dependencies, deliverables)
2. Has a **Prompt Body** — this is what you paste to the coding agent
3. Has **Verification Steps** — run these before marking the prompt complete in `04_TRACKER.md`

**Rules for using prompts:**
- Complete ONE prompt fully before starting the next
- After each prompt: run verification steps, update `04_TRACKER.md`, commit to git
- If a prompt produces incomplete output, re-run it with the failures described explicitly
- Prompts 3 and 4 may be worked in parallel (they don't depend on each other, only on Prompt 2)
- Never skip a prompt

## When UHSR Results Drop — Activation Sequence

When UHSR publishes the 2026 result PDF:

1. Convert PDF to Markdown (see `01_PLAN.md` → Decision Point 3)
2. Admin panel → Upload Markdown per CET exam (one upload per exam)
3. Review validation report — check `is_passed == True`
4. Run `RankingVerifier.compare_against_published()` against UHSR's published ordering
5. Try criterion orderings until `agreement_percentage == 100.0`
6. Update `PLACEHOLDER_CONFIG` in `ranking_config.py` with the verified config
7. Change version string from `"v1-UNVERIFIED-placeholder"` to `"v1-verified-2026"`
8. Admin panel → Publish dataset
9. `ranking_disclaimer` disappears automatically
10. Calculator goes live — no code changes, no redesign
