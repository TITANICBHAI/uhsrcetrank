# UHSR CET Rank Calculator 2026 — Acceptance Tests

> These tests define release readiness. A green build is not enough if the site can display an incorrect or misleading position.

## A. Identity and content

- [ ] Product is clearly branded as an independent candidate utility.
- [ ] No page claims affiliation, endorsement, operation, or official status.
- [ ] Official UHSR portal link is present and points to `https://www.uhsrcetadmissions.in/`.
- [ ] No official logo, emblem, seal, or copied government asset is present.
- [ ] “Estimated Merit Position” is used consistently.
- [ ] Official-result warning is visible on the home page, result page, methodology, FAQ, and PDF.

## B. Truthful unavailable state

- [ ] With no published dataset, calculator controls are disabled or clearly unavailable.
- [ ] No candidate details, ranks, counts, dates, countdowns, or live-result claims are fabricated.
- [ ] Every CET option with no published dataset is visibly unavailable.
- [ ] Direct result URLs cannot create a fake result from query parameters.

## C. Import correctness

- [ ] Repeated headers are skipped.
- [ ] Page numbers and separator rows are skipped.
- [ ] Roll-number normalization is deterministic.
- [ ] Dates retain raw values when parsing fails.
- [ ] Numeric values are not silently clamped.
- [ ] Unknown columns are reported or retained.
- [ ] Conflicting duplicate roll numbers block publication.
- [ ] Every failed row has a reason and source reference.
- [ ] No raw official file is exposed through a public endpoint.

## D. Ranking correctness

- [ ] The active ranking configuration is stored with the dataset.
- [ ] The ranking version appears on the result.
- [ ] A placeholder/unverified configuration shows a prominent warning.
- [ ] Published-order mode is supported when official order exists.
- [ ] Reconstructed criteria are configurable, not scattered in UI or routes.
- [ ] Missing ranking inputs follow an explicit policy.
- [ ] Unresolved ties are not falsely reported as official ordering.
- [ ] Ranking is deterministic for identical inputs.
- [ ] Verification reports disagreements and missing/extra candidates.

## E. Public lookup

- [ ] Valid known roll number returns the correct exam-specific record.
- [ ] Roll number from another CET exam does not silently match the wrong dataset.
- [ ] Unknown roll number returns an inline not-found message.
- [ ] No published dataset returns unavailable, not not-found.
- [ ] Invalid input returns a stable validation error.
- [ ] Network failure is inline and does not use `alert()`.
- [ ] Candidate values are HTML-escaped.
- [ ] Public API does not expose admin validation diagnostics.
- [ ] Search routes are rate-limited or protected by a documented edge rule before production traffic.

## F. Privacy and security

- [ ] Admin secret exists only in environment configuration.
- [ ] Admin UI is not linked from public navigation.
- [ ] Admin route is noindex but also protected by authentication.
- [ ] Admin responses are `Cache-Control: no-store`.
- [ ] CORS is restricted in production.
- [ ] Upload size and type are restricted.
- [ ] Production logs contain no secrets, full rows, names, or DOBs.
- [ ] No public browse-all-candidates endpoint exists.
- [ ] Other candidates' personal details are not shown in “candidates above.”

## G. Accessibility and responsive behavior

- [ ] Page headings are semantic and ordered.
- [ ] Every form control has a visible label.
- [ ] Keyboard focus is visible.
- [ ] Errors are associated with controls.
- [ ] Tables scroll or reflow on small screens.
- [ ] Site works at 320px, 768px, and desktop widths.
- [ ] Contrast is sufficient without relying on colour alone.

## H. Release smoke test

Run locally with no dataset:

```text
Home → unavailable state → methodology → FAQ → official portal link
```

Run locally with a synthetic private fixture:

```text
Import → validate → preview → publish → search found
Search missing → not found
Unpublish → unavailable
Replace dataset → only replacement active
Print/save report → unofficial browser report
```

The synthetic fixture must never be deployed or visible as production data.
