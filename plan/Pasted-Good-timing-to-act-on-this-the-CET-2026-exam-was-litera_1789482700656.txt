### PROMPT 3 — Markdown Importer

> Use after Prompt 2. The hardest and most important piece.

---

Build `app/importer/` for the UHSR CET Rank Calculator backend. This module takes a raw Markdown string (messy PDF-converted output) and returns a validated list of candidate objects ready for database insertion.

**The real problem you're solving:** UHSR publishes large PDFs. When converted to Markdown, the output is garbage. You must handle all of this:
- Pipe-delimited tables: `| Sr No | Roll Number | Name | Score | Percentile | DOB | Category |`
- Repeated table headers on every PDF page (detect and skip them)
- Rows split across two lines (multiline candidate names)
- Page numbers embedded mid-table: "Page 3 of 47", lone digit rows
- Empty cells as `"-"`, `"N/A"`, `"--"`, `"NA"`, `""`
- Scores with `%` suffix: `"78.50 %"`, `"78.50%"`, `"78.50"`
- Dates in all formats: `"15/08/2000"`, `"15-08-2000"`, `"15.08.2000"`, `"15 Aug 2000"`, `"15 AUGUST 2000"`
- Names in ALL CAPS (title-case them)
- Non-breaking spaces (`\xa0`), zero-width spaces
- Duplicate roll numbers (same candidate appearing twice)
- Column count shifting between rows
- Columns with unexpected names

**Module: `table_extractor.py`**

```python
@dataclass
class RawTable:
    headers: list[str]
    rows: list[list[str]]

class TableExtractor:
    def extract(self, markdown: str) -> list[RawTable]: ...
```

Logic:
1. Split into lines
2. Detect table lines: line matches `^\|.*\|$`
3. Separator lines `^\|[-:| ]+\|$` — skip
4. Group consecutive table lines into blocks
5. Parse cells: split on `|`, strip whitespace, replace `\xa0` and zero-width chars with space, strip again
6. Detect repeated header rows: if a data row matches the header values (case-insensitive), skip it
7. Multiline row merging: if a row has significantly fewer cells than the header (< header_count - 2), attempt to merge it with the next line before parsing
8. Strip page-number rows: matches `^Page \d+ of \d+$` or is a lone integer

**Module: `candidate_normalizer.py`**

```python
from enum import Enum

class KnownField(Enum):
    SERIAL_NO = "serial_no"
    ROLL_NUMBER = "roll_number"
    NAME = "name"
    CET_SCORE = "cet_score"
    PERCENTILE = "percentile"
    DOB = "dob"
    CATEGORY = "category"
    CET_EXAM = "cet_exam"
    UNKNOWN = "unknown"

@dataclass
class NormalizeResult:
    success: bool
    candidate: Candidate | None
    reason: str | None
    warnings: list[str]

class CandidateNormalizer:
    def map_headers(self, headers: list[str]) -> list[KnownField]: ...
    def normalize_row(self, row: dict[KnownField, str], cet_exam: str, cet_group: str) -> NormalizeResult: ...
```

`map_headers`: fuzzy lowercase matching against these aliases:
```python
FIELD_ALIASES = {
    KnownField.ROLL_NUMBER: ["roll number", "roll no", "roll no.", "cet roll number", "cet roll no", "cet roll no."],
    KnownField.NAME: ["name", "candidate name", "applicant name"],
    KnownField.CET_SCORE: ["cet score", "score", "cet %", "cet percentage", "cet marks"],
    KnownField.PERCENTILE: ["percentile", "cet percentile", "cet percentile score"],
    KnownField.DOB: ["dob", "date of birth", "d.o.b", "d.o.b.", "birth date"],
    KnownField.CATEGORY: ["category", "cat", "caste"],
    KnownField.CET_EXAM: ["course", "exam", "cet exam", "cet", "examination"],
    KnownField.SERIAL_NO: ["sr no", "sr. no", "sr. no.", "s.no", "serial", "sno"],

```

`normalize_row` rules:
- `roll_number`: required, strip + uppercase. If blank → NormalizeResult(success=False, reason="Missing roll number")
- `name`: strip. If ALL CAPS → title-case it. Allow null (add warning, don't fail)
- `cet_score`: strip, remove `%`, `%` (unicode percent), spaces. Parse as float. None if null-like (`-`, `n/a`, `na`, `--`, ``)
- `percentile`: same as score. If parsed value outside 0..100 range, keep it but add warning
- `dob`: try these in order using `dateutil.parser.parse` with `dayfirst=True`, fall back to manual `re` parsing for `dd/MM/yyyy`, `dd-MM-yyyy`, `dd.MM.yyyy`. None if unparseable — add warning, do NOT fail
- `category`: strip + uppercase. None if blank
